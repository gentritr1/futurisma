# D6 — Actual loaded-world contract

`regenerate-tideline-manifest.mjs` parses the delivered Foundry GLB. It counts exported semantic instance anchors, loaded mesh primitives and loaded triangles, then writes the playable manifest and a SHA-256 of that exact GLB. The anchors retain instance identity after geometry is merged into sector/material batches.

`validate-tideline-contract.mjs` independently loads that GLB and uses the same assertion as the playable loader. It verifies the hash, unique anchor identities and all census, primitive and triangle counts. It deliberately corrupts each field and requires rejection. The playable loader performs its assertion before adding runtime decoration; on failure it releases already-loaded resources.

Observed by that validator: 74,554 triangles, 55 primitives and 149 unique instance anchors. Crown and flight-lens counts are both zero. The older path was a retired-prototype notice at the starting commit; it is now an explicit contract for the playable world.

The complete source/build gate includes this assertion and the new hardware/CHAIN checks. The historical package checks report missing archives and skip them; they provide no verification of those unavailable files. A final captured gate log accompanies the delivery index.
