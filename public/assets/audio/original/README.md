Meridian Afterimage is an original 110-second instrumental made for Futurisma.

The 174 BPM arrangement has an eight-bar introduction, 32 bars of drums and
bass, an eight-bar atmospheric break, a 24-bar return and an eight-bar outro.
Layered suspended pads, syncopated percussion, a restrained sub bass and a soft
five-note signal suggest the late-night city without covering the craft cues.

Every sound is generated by `scripts/build-original-soundtrack.py`: no external
recordings or third-party samples are used. This original may be shipped with
the game. Imported DJ mixes remain separately ignored in `assets/audio/music`.

Rebuild from the project root with `python3 scripts/build-original-soundtrack.py`
(NumPy and ffmpeg required). The generator measures the master, applies two-pass
loudness matching, measures the encoded MP3, and records duration, loudness,
true peak and SHA-256 in the adjacent JSON report. The soundtrack validator
checks the report against the shipped bytes.

The automatic playlist combines private imports with this instrumental. A fresh
clone uses this track alone. `?music=synth` selects the existing procedural score;
`?music=0` silences both. The music slider, radio duck, pause and mute all use the
existing shared audio bus.
